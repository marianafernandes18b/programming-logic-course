# Programming Logic Challenges 🧠

## 📝 About This Repository
This repository is a personal log of my learning journey in technology and cybersecurity. It contains a collection of programming logic exercises, code structures, and computational problems solved during my specialization course.

The main goal here is to build a rock-solid foundation in structured thinking, pattern recognition, and algorithm logic.

## 🛠️ Tech Stack & Concepts Covered
* **JavaScript (ES6):** Used as the primary language to write clean and structured logic.
* **HTML5:** Utilized as a minimal interface to render scripts and handle interactive user inputs.
* **Core Topics Explored:**
  * Variables, data types, and constants.
  * Conditional structures (`if`, `else if`, `else`) for decision-making.
  * Loops and iterations (`for`, `while`) to automate tasks.
  * Functions, parameters, and block scope handling.

## 📂 Project Structure
Each folder or file in this repository represents a specific logical challenge, interactive script, or algorithmic task completed during the module.
